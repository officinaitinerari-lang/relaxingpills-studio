Relaxing Pills Studio — Privacy Policy

Last updated: 8 November 2026

Relaxing Pills Studio is a private publishing tool used only by the owner of the YouTube channel Relaxing Pills to upload and manage the channel's own videos. It is not offered to the public and does not have other users.

YouTube API Services

Relaxing Pills Studio uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Information handled through the YouTube API is also subject to the Google Privacy Policy.

What data the tool accesses

  • Basic information about the owner's own YouTube channel (channel ID, title, statistics).
  • The owner's own videos, playlists, captions and thumbnails, in order to upload, schedule and organise them.

The tool does not access, collect or store data about viewers or any other YouTube users.

How data is stored

The only stored credential is the OAuth refresh token of the channel owner, kept as an encrypted secret in the owner's GitHub repository and used solely by the owner's automated workflow. Video files and metadata are created by the owner and are not shared with third parties. No data is sold, shared or used for advertising.

Revoking access

Access can be revoked at any time from the Google account security settings: myaccount.google.com/permissions.
